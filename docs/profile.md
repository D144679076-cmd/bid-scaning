# Profile — Software Officer, UNEST Việt Nam

**AI Pipeline Agents & Automation · Web/App Development**

I am a software developer at **UNEST Việt Nam** ([unestgroup.com](https://unestgroup.com)) — a company applying AI, automation, and digital transformation to enterprise operations. My focus: building **automation and AI pipeline agents** — systems that ingest real-world content, process it with AI (OCR, LLMs), and turn it into working outcomes: searchable learning content, auto-generated material, actionable data.

## Products I build

- **Educora LMS** ([educora.vn](https://educora.vn)) — school-wide digital learning platform: online examinations with anti-cheating at scale, AI-powered course and question generation, real-time dashboards, adaptive practice, and digital classrooms. Aligned to the GDPT 2018 standard; 100% data ownership stays with teachers.

- **IELTS Academy** ([ielts-lms.lynx-lab.org](https://ielts-lms.lynx-lab.org)) — an AI-powered IELTS practice LMS. Behind it runs an **AI + OCR pipeline**: paper materials — textbooks, worksheets, scanned tests — flow through extraction, structuring, and AI generation to become ready-to-study digital content; AI agents assist learner practice and feedback.

- **LynxLab** ([github.com/LynxLabVN](https://github.com/orgs/LynxLabVN)) — my lab for Python agent tooling: `agent-core`, an MIT-licensed agent runtime, and `office-agent` for office workflow automation.

## Core skills

AI pipeline & agent development (OCR → LLM → structured output) · workflow automation · full-stack web/app development · full-text search (indexing, relevance, Vietnamese retrieval) · LLM integration & AI-assisted generation · Python.

## How I work

I start from a manual process — materials stuck on paper, content prep by hand, information nobody can find — and turn it into an automated pipeline: ingestion → OCR/AI processing → structured output, wrapped in a clean web app.
